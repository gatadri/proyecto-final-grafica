## NUEVOS MODELOS EN BASE DE DATOS

### 1. Skin (Avatares)
- id: Identificador único
- nombre: Nombre del skin
- descripcion: Descripción del skin
- imagen: Ruta de la imagen (desde /imagenes/avatares/)
- avatar_key: Clave única para identificar el avatar
- precio: Costo en monedas
- rareza: comun, raro, legendario
- activo: Si está disponible en la tienda
- created_at: Fecha de creación

### 2. SkinComprada
- nino: Relación con el niño
- skin: Relación con el skin
- fecha_compra: Fecha de compra
- Unique constraint: (nino, skin)

### 3. Sticker
- id: Identificador único
- nombre: Nombre del sticker
- descripcion: Descripción del sticker
- imagen: Ruta de la imagen (desde /imagenes/stickers/)
- precio: Costo en monedas
- rareza: comun, raro, legendario
- activo: Si está disponible en la tienda
- created_at: Fecha de creación

### 4. StickerComprado
- nino: Relación con el niño
- sticker: Relación con el sticker
- fecha_compra: Fecha de compra
- Unique constraint: (nino, sticker)

## NUEVAS APIs IMPLEMENTADAS

### APIs de Tienda (Niños)

1. **GET /api/tienda/skins?nino_id={id}**
   - Lista todas las skins disponibles
   - Indica si el niño ya las compró
   - Indica cuál está equipada
   - Status: ✅ 200 OK

2. **POST /api/tienda/skins/comprar**
   - Body: { nino_id, skin_id }
   - Compra una skin
   - Descuenta monedas
   - Valida que tenga suficientes monedas
   - Status: ✅ Funcional

3. **POST /api/tienda/skins/equipar**
   - Body: { nino_id, skin_id }
   - Equipa una skin comprada
   - Cambia el avatar del niño
   - Status: ✅ Funcional

4. **GET /api/tienda/stickers?nino_id={id}**
   - Lista todos los stickers disponibles
   - Indica si el niño ya los compró
   - Status: ✅ 200 OK

5. **POST /api/tienda/stickers/comprar**
   - Body: { nino_id, sticker_id }
   - Compra un sticker
   - Descuenta monedas
   - Valida que tenga suficientes monedas
   - Status: ✅ Funcional

### APIs de Inventario (Profesores/Director)

6. **GET /api/inventario/tienda**
   - Lista todas las skins y stickers del sistema
   - Solo para profesores y directores
   - Status: ✅ 401 (requiere autenticación)

7. **POST /api/inventario/tienda**
   - Body: { tipo: 'skin'|'sticker', nombre, descripcion, imagen, precio, rareza, avatar_key }
   - Crea nuevos items en la tienda
   - Solo para profesores y directores
   - Status: ✅ Funcional

8. **PATCH /api/inventario/{tipo}/{id}**
   - Actualiza un item existente
   - Solo para profesores y directores
   - Status: ✅ Funcional

9. **DELETE /api/inventario/{tipo}/{id}**
   - Elimina un item de la tienda
   - Solo para profesores y directores
   - Status: ✅ Funcional
