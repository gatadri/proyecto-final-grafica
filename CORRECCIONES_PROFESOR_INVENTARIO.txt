3. FLUJO DE CREACIÓN DE SKIN/STICKER
═══════════════════════════════════════════════════════════════════

NUEVO FLUJO:

1. Usuario hace clic en "Nuevo Ítem"
2. Selecciona tipo (Skin o Sticker)
3. Completa campos:
   - Nombre *
   - Rareza (Común/Raro/Legendario)
   - Precio
   - Imagen * (archivo JPG/PNG)
   - Descripción
4. Selecciona archivo de imagen
5. Ve preview de la imagen
6. Hace clic en "Guardar"
7. Backend:
   - Recibe FormData
   - Guarda imagen con nombre único
   - Genera avatar_key automáticamente (para skins)
   - Crea registro en BD
8. Frontend actualiza lista

CAMPOS AUTOMÁTICOS:
- avatar_key: nombre.toLowerCase().replace(/\s+/g, '_')
- Nombre de archivo: tipo_timestamp_nombreoriginal.ext
- Ruta: imagenes/avatares/ o imagenes/stickers/

7. ENDPOINTS ACTUALIZADOS
═══════════════════════════════════════════════════════════════════

GET /api/profesor/estudiantes
  - Retorna lista de niños del profesor autenticado
  - Incluye: nombre, apellido, grado, monedas, nivel, experiencia, racha

POST /api/inventario/tienda
  - Content-Type: multipart/form-data
  - Campos:
    * tipo: 'skin' | 'sticker'
    * nombre: string
    * descripcion: string
    * precio: number
    * rareza: 'comun' | 'raro' | 'legendario'
    * imagen: File
    * avatar_key: string (opcional, se genera automático)
