   Archivo subido: "pirata.jpg"
   Guardado como: "skin_1234567890_pirata.jpg"
   Ubicación: frontend/public/imagenes/avatares/skin_1234567890_pirata.jpg
   En BD: "skin_1234567890_pirata.jpg"

   Ruta: /imagenes/avatares/skin_1234567890_pirata.jpg
   Fallback: /imagenes/avatares/nino.png

4. Visualización en tienda niño:
   Ruta: /imagenes/avatares/skin_1234567890_pirata.jpg
   Fallback: /imagenes/avatares/nino.png

5. Descarga PDF (stickers):
   - Carga imagen desde: /imagenes/stickers/[nombre]
   - Convierte a base64
   - Genera PDF con jsPDF
   - Descarga automáticamente

6. CÓDIGO BACKEND - Guardado de Archivos
═══════════════════════════════════════════════════════════════════

```python
if imagen_file:
    import time
    file_name = f"skin_{int(time.time())}_{imagen_file.name}"
    file_path = os.path.join(settings.MEDIA_ROOT, 'imagenes', 'avatares', file_name)
    
    # Asegurar que el directorio existe
    os.makedirs(os.path.dirname(file_path), exist_ok=True)
    
    # Guardar el archivo
    with open(file_path, 'wb+') as destination:
        for chunk in imagen_file.chunks():
            destination.write(chunk)
    
    # Guardar solo el nombre en BD
    imagen_nombre = file_name
```
