# SOLUCION - BLOQUEO AL EQUIVOCARSE EN EJERCICIOS

## PROBLEMA
Cuando el niño se equivocaba en el primer intento, podía seleccionar otra opción pero NO podía enviarla. El botón "Confirmar Respuesta" quedaba bloqueado.

## CAUSA
El código original solo manejaba dos casos:
1. Respuesta correcta → avanzar al siguiente ejercicio
2. Segundo intento fallido → avanzar al siguiente ejercicio

NO había código para manejar el caso de primer intento incorrecto, lo que causaba que el feedback quedara activo y bloqueara el botón.

## SOLUCION APLICADA

Se agregó un bloque `else` en la función `responder()` para manejar el primer intento incorrecto:

```typescript
if (correcto || this.intentos >= 2) {
  // Avanzar al siguiente ejercicio
  ...
} else {
  // Primer intento incorrecto - permitir segundo intento
  setTimeout(() => {
    this.feedback = null;
    this.respuestaSeleccionada = '';
  }, 1500);
}
```

## COMO FUNCIONA AHORA

### Flujo corregido:

1. **Niño selecciona respuesta incorrecta (primer intento)**
   - Se muestra mensaje: "Intenta de nuevo"
   - Espera 1.5 segundos
   - Limpia el feedback
   - Limpia la selección
   - El niño puede seleccionar otra opción
   - El botón se habilita al seleccionar

2. **Niño selecciona respuesta correcta**
   - Se muestra mensaje: "¡Correcto! +10 puntos" (o +5 si es segundo intento)
   - Espera 1.5 segundos
   - Avanza al siguiente ejercicio

3. **Niño falla el segundo intento**
   - Se muestra: "Incorrecto. La respuesta era: X"
   - Espera 1.5 segundos
   - Avanza al siguiente ejercicio (sin puntos)
