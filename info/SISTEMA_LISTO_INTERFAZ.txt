## 🤖 QUE HACE EL SISTEMA ML

### Por Cada Respuesta:
1. **Analiza** tipo de error (multiplicacion, division, fracciones)
2. **Mide** nivel de concentración (focus_score)
3. **Detecta** distracciones (cambios de pestaña, inactividad)
4. **Guarda** todo en base de datos

### Si Detecta Distracción:
- Focus score < 0.4
- Muestra pantalla de descanso (10 segundos)
- Pausa los ejercicios
- Guarda evento en EventoDistraccion

### Para Reportes:
- Identifica temas problemáticos
- Prepara notificaciones para padre/profesor
- Genera estadísticas de concentración
