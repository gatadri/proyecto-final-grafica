## COMO PROBAR EL SISTEMA

### OPCION 1: Simulacion Automatica (Recomendado)

Esta es la forma mas rapida de ver todo el sistema en accion.

1. Inicia el servidor Django:
```bash
cd backend
python manage.py runserver
```

2. En otra terminal, ejecuta la simulacion:
```bash
cd backend
python simular_prueba_ml.py
```

La simulacion hara lo siguiente:
- Simulara un nino resolviendo 12 ejercicios
- Los primeros 3 ejercicios: concentrado (pocos errores)
- Ejercicios 4-7: empezando a distraerse
- Ejercicios 8-12: muy distraido (muchos errores)
- Enviara cada respuesta al ML para analisis
- Mostrara cuando se detecta distraccion
- Generara reporte de errores
- Mostrara estadisticas
- Preparara notificaciones para padre/profesor

### OPCION 2: Prueba Manual con Postman/curl

#### 1. Ver tareas disponibles del nino
```
GET http://localhost:8000/api/tareas/nino/tareas?nino_id=17
```

#### 2. Ver una tarea especifica
```
GET http://localhost:8000/api/tareas/nino/tareas/11?nino_id=17
```

Respuesta incluye todos los ejercicios con sus opciones.

#### 3. Analizar una respuesta (simular que el nino respondio)
```
POST http://localhost:8000/api/tareas/ml/analizar-respuesta
Content-Type: application/json

{
  "nino_id": 17,
  "ejercicio_id": 1,
  "tiempo_ms": 15000,
  "correcto": false,
  "tab_blur_count": 3,
  "idle_ms": 5000,
  "erratic_clicks": 8
}
```

Respuesta:
```json
{
  "prediccion": {
    "error_type": "multiplicacion",
    "prob_mistake_next": 0.85
  },
  "distraccion": {
    "requiere_descanso": true,
    "focus_score": 0.35
  }
}
```

Si `requiere_descanso: true`, el frontend debe mostrar la pantalla de descanso.

#### 4. Repetir paso 3 para varios ejercicios

Repite el paso 3 cambiando los valores:
- `ejercicio_id`: 1, 2, 3, 4, etc.
- `tiempo_ms`: varia el tiempo (3000-20000)
- `correcto`: true o false
- `tab_blur_count`: 0-6 (cuantas veces cambio de pestana)
- `idle_ms`: 0-8000 (tiempo inactivo)
- `erratic_clicks`: 0-12 (clicks fuera de elementos)

**NOTA:** El ML necesita minimo 3 respuestas para detectar distracciones.

#### 5. Ver reporte de errores
```
GET http://localhost:8000/api/tareas/ml/reporte-errores?nino_id=17
```

Muestra:
- Tipos de errores detectados
- Cantidad de cada tipo
- Probabilidad promedio

#### 6. Ver estadisticas completas
```
GET http://localhost:8000/api/tareas/ml/estadisticas?nino_id=17
```

Muestra:
- Focus promedio
- Total de distracciones
- Errores por tipo
- Ultimos eventos

#### 7. Notificar a padre y profesor
```
POST http://localhost:8000/api/tareas/ml/notificar
Content-Type: application/json

{
  "nino_id": 17
}
```

Prepara notificaciones con:
- Email del padre
- Email del profesor
- Lista de temas que necesita reforzar

## QUE VER EN LA BASE DE DATOS

### Tabla: tareas_prediccionerror

```sql
SELECT * FROM tareas_prediccionerror WHERE nino_id = 17;
```

Veras:
- tipo_error: multiplicacion, division, fracciones, etc.
- probabilidad: 0.0 a 1.0
- fecha_prediccion
- notificado: si se notifico al padre/profesor

### Tabla: tareas_eventodistruccion

```sql
SELECT * FROM tareas_eventodistruccion WHERE nino_id = 17;
```

Veras:
- focus_score: 0.0 a 1.0 (menor = mas distraido)
- tab_blur_count: cambios de pestana
- idle_ms: tiempo inactivo
- erratic_clicks: clicks erraticos
- descanso_mostrado: si se mostro la pantalla

---

## INTERPRETACION DE RESULTADOS

### Focus Score
- **0.8 - 1.0**: Muy concentrado
- **0.6 - 0.8**: Concentracion normal
- **0.4 - 0.6**: Empezando a distraerse
- **< 0.4**: Muy distraido (se muestra descanso)

### Tipos de Error
- **multiplicacion**: Errores en ejercicios de multiplicacion
- **division**: Errores en ejercicios de division
- **fracciones**: Errores en ejercicios de fracciones
- **procedimiento**: Error en el procedimiento
- **inatencion**: Error por falta de atencion
- **conceptual**: No entiende el concepto

### Indicadores de Distraccion
- **tab_blur_count > 3**: Cambia mucho de pestana
- **idle_ms > 5000**: Demasiado tiempo inactivo
- **erratic_clicks > 8**: Muchos clicks sin sentido
- **tiempo_ms muy alto o muy bajo**: Responde sin pensar o tarda mucho
