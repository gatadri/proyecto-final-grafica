## 📊 QUE ESPERAR DEL SISTEMA

### Al Resolver Ejercicios:

**Si responde bien y rápido:**
- No se detecta error
- Focus score alto (> 0.6)
- Continúa normalmente

## 📝 INTEGRACIÓN EN EL FRONTEND

Si el frontend NO está integrando el ML automáticamente, revisa:

### 1. Servicio ML Service

Asegúrate de tener:
```typescript
// frontend/src/app/services/ml.service.ts
import { Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';

@Injectable({
  providedIn: 'root'
})
export class MLService {
  private apiUrl = 'http://localhost:8000/api/tareas/ml';

  constructor(private http: HttpClient) { }

  analizarRespuesta(datos: any) {
    return this.http.post(`${this.apiUrl}/analizar-respuesta`, datos);
  }
}
```

### 2. Componente de Ejercicios

En el componente donde el niño resuelve ejercicios:

```typescript
import { MLService } from './services/ml.service';

// En el método que procesa la respuesta:
onSubmitRespuesta(ejercicio, respuesta) {
  const datos = {
    nino_id: this.ninoActual.id,
    ejercicio_id: ejercicio.id,
    tiempo_ms: this.tiempoRespuesta,
    correcto: respuesta === ejercicio.respuesta_correcta,
    tab_blur_count: this.tabBlurCount,
    idle_ms: this.idleMs,
    erratic_clicks: this.erraticClicks
  };

  this.mlService.analizarRespuesta(datos).subscribe(result => {
    if (result.distraccion?.requiere_descanso) {
      // Mostrar pantalla de descanso
      this.pantallaDescanso.iniciarDescanso();
    }
  });
}
```
