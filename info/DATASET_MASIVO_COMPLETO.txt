## 🎯 INTEGRACIÓN CON FRONTEND

En el componente de ejercicios, después de cada respuesta:

```typescript
// Llamar al endpoint
this.http.post('/api/tareas/analizar-respuesta/', {
  nino_id: this.ninoId,
  ejercicio_id: this.ejercicioActual.id,
  tiempo_ms: tiempoRespuesta,
  correcto: esCorrecta,
  tab_blur_count: 0,
  idle_ms: 0,
  erratic_clicks: 0
}).subscribe(response => {
  // Verificar si requiere descanso
  if (response.distraccion.requiere_descanso) {
    // Mostrar pantalla de distracción
    this.mostrarPantallaDistraccion(response.distraccion.motivo);
  }
});
```

### Mensajes Sugeridos por Motivo:

const mensajes = {

## 🐛 TROUBLESHOOTING

### Error: "Memory Error"
- Reduce NUM_STUDENTS en el generador
- Cierra otras aplicaciones

### Entrenamiento muy lento
- Reduce epochs en train.py
- Aumenta batch_size

### Precisión muy baja
- Genera dataset más grande
- Ejecuta entrenar_todo.py de nuevo

### Modelos no cargan
- Verifica que los .h5 y .pkl existen en ml/models/
- Reentrenar: `python train.py`
