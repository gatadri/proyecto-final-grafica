### 1. 🎮 PANTALLA DE DESCANSO CON MINIJUEGOS

**Antes:**
```
┌─────────────────────┐
│   😌                │
│ ¡Hora de descanso!  │
│                     │
│   [Contador 10s]    │
│                     │

```

**Ahora:**
```
┌─────────────────────────────┐
│   😌 Momento de Descanso    │
│                             │
│  ¿Cuál es el color ROJO?    │
│                             │
│  [🔴]  [🟢]  [🔵]  [🟡]    │
│                             │
│  [Responde correctamente]   │
│                             │
│       🎉 ¡Excelente!        │
│                             │
│   [Contador 5s] 🌟          │
└─────────────────────────────┘
```

#### 3 Tipos de Juegos Incluidos:

**🎨 COLORES**
- Pregunta: "¿Cuál es el color ROJO?"
- Muestra 4 botones de colores
- El niño selecciona el correcto

**🔢 NÚMEROS**
- Pregunta: "¿Cuál número es MAYOR?"
- O "¿Cuánto es 2 + 2?"
- 4 opciones numéricas

**⭐ FORMAS**
- Pregunta: "¿Cuál es un CÍRCULO?"
- Muestra: ⭕ ⬛ 🔺 ⭐
- Selección visual

#### Características:
✅ **13 juegos diferentes** (selección aleatoria)
✅ **Feedback inmediato** (verde si acierta, rojo si falla)
✅ **Reintento permitido** si falla
✅ **Animaciones suaves** (botones crecen, tiemblan)
✅ **Mensajes motivadores** ("¡Excelente!", "¡Inténtalo de nuevo!")
✅ **Cuenta regresiva de 5s** después de acertar
