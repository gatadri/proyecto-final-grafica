2. SERVICIO DE AUDIO (AudioService)
═══════════════════════════════════════════════════════════════════

Ubicación: src/app/core/services/audio.service.ts

Características:
✓ Servicio centralizado para gestionar todos los audios
✓ Tres tipos de audio: GENERAL, TUTORIALES, EJERCICIOS
✓ Volumen bajo automático (20%)
✓ Reproducción en loop
✓ Persistencia de estado en localStorage
✓ Control de reproducción/pausa
✓ Detención automática al cambiar de audio

Métodos principales:
- play(type): Reproduce un audio específico
- pause(type): Pausa un audio específico
- toggle(type): Alterna entre reproducir/pausar
- stopAll(): Detiene todos los audios
- isPlaying(type): Verifica si un audio está sonando
- isEnabled(type): Verifica si un audio estaba activado
- setVolume(type, volume): Ajusta el volumen

4. CARACTERÍSTICAS TÉCNICAS
═══════════════════════════════════════════════════════════════════

Volumen:
- Todos los audios: 20% (0.2)
- Configurable mediante setVolume()

Loop:
- Todos los audios se repiten infinitamente
- Propiedad: audio.loop = true

Persistencia:
- Estados guardados en localStorage
- Clave: 'audioStates'
- Se restauran al recargar la página

Gestión de memoria:
- Solo un audio puede sonar a la vez
- Al reproducir uno nuevo, se detiene el anterior
- Se pausan al destruir componentes (ngOnDestroy)

5. FLUJO DE USUARIO
═══════════════════════════════════════════════════════════════════

NIÑO - Dashboard:
1. Entra al dashboard
2. Ve botón flotante de música
3. Hace clic para activar/desactivar
4. Audio se reproduce en loop
5. Estado se guarda
6. Al volver, se restaura el estado

NIÑO - Tutorial:
1. Entra al tutorial
2. Ve botón de música en encabezado
3. Hace clic para activar/desactivar
4. Audio se reproduce en loop
5. Estado se guarda
6. Al volver, se restaura el estado

NIÑO - Tareas/Prácticas:
1. Entra a una tarea o práctica
2. Audio se reproduce AUTOMÁTICAMENTE
3. No hay control manual
4. Audio continúa durante toda la sesión
5. Se detiene al salir

PROFESOR/PADRE/DIRECTOR - Tutorial:
1. Entra al tutorial
2. Ve botón de música en encabezado
3. Hace clic para activar/desactivar
4. Audio se reproduce en loop
5. Estado se guarda
6. Al volver, se restaura el estado
