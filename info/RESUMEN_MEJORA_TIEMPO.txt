## 🎯 Cómo funciona

### Lógica Principal:

```
1. El niño completa un ejercicio
2. Backend obtiene sus últimos 30 ejercicios (excluyendo outliers > 3 min)
3. Calcula promedio de tiempo de respuesta
4. Compara tiempo actual vs 3x promedio
5. Si tiempo_actual > (promedio * 3) → Activa pantalla de descanso
```

### Ejemplo:
```
Promedio del niño: 4 segundos
Umbral 3x: 12 segundos

- Tarda 5s → Normal ✅
- Tarda 8s → Normal ✅  
- Tarda 13s → DESCANSO 🛑 (excedió el triple)
```

## 📊 Estadísticas de Detección

El sistema detecta distracción por **4 métodos**:

1. ⏱️ **Tiempo excesivo** (3x promedio) ← Lo que pediste
2. ❌ **3 errores consecutivos**
3. 📉 **Focus score bajo** (< 0.4)
4. 🔄 **Comportamiento errático** (tab blur, idle, clicks)
