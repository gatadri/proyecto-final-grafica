EJECUTAR AHORA (RECOMENDADO):
==============================

1. Abrir terminal en: c:\laragon\www\proyecto_adri_angular

2. Ejecutar:
   cd ml
   python entrenar_todo.py

3. Esperar ~5-10 minutos mientras:
   - Genera 15,000 registros de datos
   - Entrena modelo FFN (clasificación de errores)
   - Entrena modelo RNN (predicción de focus)
   - Valida que todo funcione

4. Reiniciar Django:
   cd ..\backend
   python manage.py runserver

¡LISTO! El sistema detectará automáticamente:
- Errores consecutivos (3+)
- Tiempo excesivo (3x promedio)
- Bajo focus (<0.4)

RESPUESTA DEL API:
==================

El endpoint /api/tareas/analizar-respuesta/ ahora retorna:

{
  "distraccion": {
    "requiere_descanso": true/false,
    "focus_score": 0.0-1.0,
    "motivo": "errores_consecutivos" | "tiempo_excesivo" | "bajo_focus"
  },
  "consecutive_errors": número,
  "excessive_time": 0 o 1
}

FRONTEND:
=========

Si distraccion.requiere_descanso === true:
  → Mostrar pantalla de distracción

Mensajes sugeridos según motivo:
- "errores_consecutivos": "¡Has cometido varios errores seguidos!"
- "tiempo_excesivo": "¡Estás tardando más de lo normal!"
- "bajo_focus": "¡Parece que estás perdiendo la concentración!"
