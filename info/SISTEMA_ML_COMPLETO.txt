## COMO FUNCIONA
========================================================================

### FLUJO COMPLETO:

1. **Niño responde un ejercicio**
   - Frontend captura: tiempo, clicks, cambios de pestaña, inactividad

2. **Se envía al backend para análisis**
   ```javascript
   this.mlService.analizarRespuesta({
     nino_id: 1,
     ejercicio_id: 1,
     tiempo_ms: 15000,
     correcto: false,
     tab_blur_count: 3,    // Cambió de pestaña 3 veces
     idle_ms: 5000,        // 5 segundos inactivo
     erratic_clicks: 8     // 8 clicks erráticos
   })
   ```

3. **El ML analiza**
   - Modelo FFN predice: tipo de error (fracciones, multiplicación, etc.)
   - Modelo RNN detecta: nivel de concentración (focus_score)

4. **Si focus_score < 0.4**
   - Se muestra pantalla de descanso de 10 segundos
   - Se guarda el evento en la BD

5. **Si hay error detectado**
   - Se guarda la predicción en la BD
   - Se puede notificar a padre y profesor

## TIPOS DE ERRORES DETECTADOS
========================================================================

- fracciones: Errores en operaciones con fracciones
- multiplicacion: Errores en multiplicaciones  
- division: Errores en divisiones
- algebra: Errores en álgebra
- geometria: Errores en geometría
- procedimiento: Errores de procedimiento
- conceptual: Errores conceptuales
- inatencion: Errores por falta de atención
- consigna: Errores al leer la consigna
- aleatorio: Errores aleatorios

## COMO USAR - GUIA RAPIDA
========================================================================

### 1. INICIAR SERVIDOR DJANGO:
```bash
cd backend
python manage.py runserver
```

### 2. PROBAR EL SISTEMA:
```bash
cd backend
python test_ml_system.py
```

### 3. INTEGRAR EN TU COMPONENTE DE EJERCICIOS:

a) Importar componente y servicio:
```typescript
import { PantallaDescansoComponent } from './components/pantalla-descanso.component';
import { MLService } from './services/ml.service';
```

b) Agregar al template:
```html
<app-pantalla-descanso></app-pantalla-descanso>
```

c) En el método de respuesta:
```typescript
@ViewChild(PantallaDescansoComponent) pantallaDescanso!;

onRespuesta(ejercicio, respuesta, tiempo) {
  this.mlService.analizarRespuesta({
    nino_id: this.ninoActual.id,
    ejercicio_id: ejercicio.id,
    tiempo_ms: tiempo,
    correcto: respuesta === ejercicio.respuesta_correcta,
    tab_blur_count: this.contadorCambiosPestana,
    idle_ms: this.tiempoInactivo,
    erratic_clicks: this.clicksErraticos
  }).subscribe(result => {
    if (result.distraccion.requiere_descanso) {
      this.pantallaDescanso.iniciarDescanso();
    }
  });
}
```
